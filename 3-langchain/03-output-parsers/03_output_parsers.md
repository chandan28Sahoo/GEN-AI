# 03 - Output Parsers & Structure

---

## 🌟 1. What is an Output Parser in LangChain?

An **Output Parser** is a component that takes the raw unstructured text response generated by an LLM (contained in an `AIMessage`) and parses/validates it into a structured format (such as a clean `str`, a Python `dict`, a JSON list, or a validated `Pydantic` object).

```
   ┌────────────────────────────────────────────────────────┐
   │                   Raw Model Response                   │
   │  AIMessage(content='{"name": "Alice", "age": 28}')     │
   └───────────────────────────┬────────────────────────────┘
                               │
                      [ Output Parser ]
                               │
   ┌───────────────────────────▼────────────────────────────┐
   │                  Structured Python Data                │
   │  {'name': 'Alice', 'age': 28}                          │
   │  or Person(name='Alice', age=28)                       │
   └────────────────────────────────────────────────────────┘
```

---

## ❓ 2. Why Do We Need Them & When Are They Used?

### The Problems They Solve:
1. **Removing Model Headers / Boilerplate**: Models often output extra text like `"Here is the information you requested: ..."` or markdown code fences (` ```json `). Output parsers automatically strip these artifacts and extract the actual data.
2. **Type Safety & Validation**: Converting strings into numbers, booleans, and lists with validation rules (e.g. `age > 18`).
3. **Format Instructions**: Parsers provide automatic `get_format_instructions()` that can be embedded directly into prompt templates to instruct the model on the exact syntax required.
4. **Seamless LCEL Chaining**: Output parsers implement the Runnable interface (`|`), so their output can immediately flow into subsequent prompts or database storage.

### Step-by-Step Code Walkthroughs

#### 1. `StrOutputParser` (Clean Text Extraction)
```python
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import PromptTemplate
from langchain_openai import ChatOpenAI

model = ChatOpenAI(model="gpt-4o")
parser = StrOutputParser()

template1 = PromptTemplate.from_template("Write a detailed report about {topic}")
template2 = PromptTemplate.from_template("Summarize this text in 3 bullet points:\n{text}")

# Chain: Prompt1 -> Model -> StrOutputParser (feeds text) -> Prompt2 -> Model -> StrOutputParser
chain = template1 | model | parser | template2 | model | parser
summary = chain.invoke({"topic": "Quantum Computing"})
print(summary)
```

---

#### 2. `JsonOutputParser` (Dynamic JSON Extraction)
```python
from langchain_core.output_parsers import JsonOutputParser
from langchain_core.prompts import PromptTemplate

parser = JsonOutputParser()

template = PromptTemplate(
    template="Generate 3 trivia questions about {topic}.\n{format_instructions}",
    input_variables=["topic"],
    partial_variables={"format_instructions": parser.get_format_instructions()}
)

chain = template | model | parser
result = chain.invoke({"topic": "Astronomy"})
# result is already a parsed Python list/dict!
print("Type:", type(result))
for q in result:
    print(q)
```

---

#### 3. `StructuredOutputParser` with `ResponseSchema`
```python
from langchain.output_parsers import StructuredOutputParser, ResponseSchema
from langchain_core.prompts import PromptTemplate

# Define expected fields and descriptions
schema = [
    ResponseSchema(name="summary", description="A 2-sentence summary of the text"),
    ResponseSchema(name="sentiment", description="Sentiment: positive, negative, or neutral"),
    ResponseSchema(name="key_entities", description="A comma-separated list of entities mentioned")
]

parser = StructuredOutputParser.from_response_schemas(schema)

template = PromptTemplate(
    template="Analyze the following review:\n{review}\n\n{format_instructions}",
    input_variables=["review"],
    partial_variables={"format_instructions": parser.get_format_instructions()}
)

chain = template | model | parser
result = chain.invoke({"review": "The food was delicious, but the service was slow. Chef Gordon was polite."})
print("Summary:", result["summary"])
print("Sentiment:", result["sentiment"])
print("Entities:", result["key_entities"])
```

---

#### 4. `PydanticOutputParser` (Strong Validation)
```python
from pydantic import BaseModel, Field
from langchain_core.output_parsers import PydanticOutputParser
from langchain_core.prompts import PromptTemplate

# Define schema with Pydantic
class PersonProfile(BaseModel):
    name: str = Field(description="Full name of the person")
    age: int = Field(gt=18, description="Age in years, must be strictly greater than 18")
    occupation: str = Field(description="Job title or occupation")
    skills: list[str] = Field(description="List of top 3 professional skills")

parser = PydanticOutputParser(pydantic_object=PersonProfile)

template = PromptTemplate(
    template="Generate a fictional professional profile for a candidate from {country}.\n{format_instructions}",
    input_variables=["country"],
    partial_variables={"format_instructions": parser.get_format_instructions()}
)

chain = template | model | parser
profile = chain.invoke({"country": "Germany"})

# Access typed attributes directly:
print(f"Name: {profile.name} (Age: {profile.age})")
print(f"Occupation: {profile.occupation}")
print(f"Skills: {', '.join(profile.skills)}")
```

## ⚖️ Output Parsers Comparison Table

| Parser | Return Type | Validation Strength | Best Use Case |
| :--- | :--- | :--- | :--- |
| `StrOutputParser` | `str` | None | Extracting text for downstream prompts/UI |
| `JsonOutputParser` | `dict` / `list` | Syntax only | Dynamic JSON without strict pre-defined schema |
| `StructuredOutputParser` | `dict` | Field presence | Extracting a handful of named fields |
| `PydanticOutputParser` | `BaseModel` | **High** (Type validation, ranges, regex) | Production pipelines & API payloads |
